# Aurum Residencia

Proyecto de programación web - Equipo 4 - FIME UANL

Este es el sitio web de una residencia para estudiantes universitarios. Básicamente es una página donde los alumnos pueden ver las habitaciones disponibles, reservar y crear una cuenta.

## Qué tiene el sitio

- Una página principal con información de la residencia
- Tipos de habitaciones (individual, doble y cuádruple)
- Formulario para hacer reservaciones
- Sistema para que los usuarios se registren e inicien sesión
- Sección donde pueden ver sus datos
